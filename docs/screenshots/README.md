# Screenshots

Drop screenshots here with the exact filenames below - the main [README](../../README.md) already references them by these paths.

Start the app (`uv run blt review`), open `http://127.0.0.1:8000`, and capture each page:

| Filename | Page | URL |
| --- | --- | --- |
| `dashboard.png` | Dashboard (flow diagram, totals, weekly charts) | `/` |
| `raw.png` | Imagens raw (confirm cover/ISBN photo pairing) | `/raw` |
| `sorted.png` | Imagens ordenadas (grouped books waiting on extraction) | `/sorted` |
| `review.png` | Livros por confirmar (the copy-paste review page) | `/review` |
| `stock.png` | Stock (searchable/sortable listing management) | `/stock` |

A few books/data in the DB (real or `DEV_MODE` test data) makes for a more representative screenshot than a totally empty state.
